## Upload to GitHub

1. Create the public repository `qisahcreativedigital.github.io`.
2. Extract this ZIP on your computer.
3. Open the extracted folder.
4. Upload **the files inside the folder**, not the parent folder itself.
5. Confirm `index.html` appears directly at the repository root.
6. Open **Settings → Pages**.
7. Choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**.
9. Save and wait for GitHub Pages deployment.
